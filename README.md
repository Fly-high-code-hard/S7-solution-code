# S7-solution-code
Этот проект был создан командой Fly high code hard в марте 2025 года в рамках хакатона S7 AI Wings.
Команда состояла из 5 человек:
1. Елизарьев Ярослав (капитан команды, ЭФ НГУ, 3 курс направления "Бизнес-информатика")
2. Метлин Александр (ФИТ НГУ, 3 курс направления "Компьютерные науки и системотехника")
3. Таки Хайдер (ММФ НГУ, 1 курс магистратуры ММФ НГУ "ИИ и анализ данных")
4. Котлярова Полина (ЭФ НГУ, 3 курс направления "Бизнес-информатика")
5. Привалова Виктория (ЭФ НГУ, 3 курс направления "Бизнес-информатика")

В рамках проекта решалась задача прогнозирования класса задержки рейсов. ML задача - мультиклассовая классификация. Сначала решалась задача регрессии, но в итоге было решено дискретизировать целевую переменную и перейти к классификации, поскольку качество регрессионных моделей было сочтено неудовлетворительным.
Классы задержки были следующие: 
1. Нет задержки
2. Задержка не более 2 часов
3. Задержка от 2 до 4 часов
4. Задержка от 4 до 6 часов
5. Задержка более 6 часов

В качестве модели был выбран XGBoost с подбором гиперпараметров через библиотеку optuna.
