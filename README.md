# S7-solution-code

Решение команды **Fly high code hard** для хакатона **S7 AI Wings (март 2025)**.

## Описание проекта

В рамках хакатона решалась задача **прогнозирования класса задержки авиарейсов** на основе исторических данных о перелетах. Задача была сформулирована как проблема **мультиклассовой классификации**, где требовалось определить интервал задержки рейса.

Первоначально рассматривалась постановка задачи в виде регрессии с прогнозированием точного времени задержки. Однако проведенные эксперименты показали, что переход к классификации позволил получить более устойчивые результаты и лучше соответствовал практическим требованиям задачи.

Использовались следующие классы задержек:

| Класс | Интервал задержки |
|:------:|-------------------|
| **0** | Отсутствие задержки |
| **1** | До 2 часов |
| **2** | От 2 до 4 часов |
| **3** | От 4 до 6 часов |
| **4** | Более 6 часов |

## Используемые методы

В качестве основной модели был выбран **XGBoost**.

Для поиска оптимальных гиперпараметров использовалась библиотека **Optuna**, что позволило автоматизировать процесс настройки модели и подобрать конфигурацию, обеспечивающую наилучшее качество на валидационной выборке.
